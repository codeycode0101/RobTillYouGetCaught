# RobTillYouGetCaught

RobTillYouGetCaught is a text-based adventure game written in Python.

## Requirements

Install the runtime dependency with:

```bash
pip install -r requirements.txt
```

## Run the game

From the project directory, start the game with:

```bash
python main.py
```

## Notes

- The game stores player progress in `player_data.json`, which is ignored by Git.
- The project uses the `keyboard` package for input handling.
